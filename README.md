# Ola-Booking-Dashboard
Hello and welcome! This repository holds the work behind the Ola Cabs booking analysis dashboard. The goal of this project is to explore booking patterns, understand key metrics, and visualize trends related to cab services in a specific region.

This project was born out of a curiosity to understand the pulse of urban mobility through data.

Dashboard Preview
The final interactive dashboard was built using Power BI. It's designed to give a clear, at-a-glance view of the most important insights.

Tech Stack
Data Processing & Analysis: SQL, Excel

Data Visualization: Power BI

How To View The Dashboard
The main output of this project is the Power BI dashboard.

Navigate to the powerbi/ folder.

Download the Ola Booking Dashboard.pbit file.

Open the file using Power BI Desktop to explore the dashboard.

The data used for the dashboard can be found in the data/ folder.

A Little About the Process
The journey started with raw booking data, which was queried using SQL and cleaned in Excel. From there, I explored different aspects like peak vehicle type, reveneue, rating, and cancellation. These insights formed the foundation for the charts and metrics you see in the final Power BI dashboard.
